# Demo Shop QA Project

## Overview

This project demonstrates QA testing activities for a demo online shop.

The goal is to practice manual testing, API testing, SQL validation and test automation.

## QA Activities

- Requirements analysis
- Test planning
- Test case design
- Bug reporting
- API testing
- Database validation
- Test automation

## Tools

- PyCharm
- Git
- GitHub
- Postman
- SQL
- Python
