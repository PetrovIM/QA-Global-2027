# Demo Shop Requirements

## 1. System Overview

Demo Shop is an online shopping application where users can browse products, manage a shopping cart and complete orders.

## 2. Functional Requirements

### User Account

The system should allow users to:

- Register a new account
- Login with valid credentials
- Logout from the system
- Reset password

### Product Catalog

The system should allow users to:

- View available products
- Search products
- Filter products by category
- Open product details

### Shopping Cart

The system should allow users to:

- Add products to cart
- Remove products from cart
- Change product quantity
- View cart total price

### Checkout

The system should allow users to:

- Enter delivery information
- Select payment method
- Confirm order
- Receive order confirmation

## 3. Non-functional Requirements

The system should:

- Respond quickly to user actions
- Protect user data
- Work correctly in supported browsers
- Be available without critical errors

## 4. Testing Scope

Testing will cover:

- UI testing
- API testing
- Database validation
- Regression testing
- Basic automation testing
